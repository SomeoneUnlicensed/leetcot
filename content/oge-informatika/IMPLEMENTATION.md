# Реализация курса ОГЭ по информатике 2026 / 2027

## Что сделано

### 1. Модели данных (Prisma schema)
Модели в `packages/db/schema.prisma`:
- `OgeLesson` — уроки теории (Markdown), привязаны к Track
- `OgeTask` — практические задания, привязаны к Track
- `OgeTaskAttempt` — попытки пользователя с ответом и результатом
- `OgeProgress` — прогресс по модулю (уроки + задания + точность)

Связаны с `Track` и `User`.

### 2. Курс ОГЭ 2026 (`oge-informatika-2026`)
- 5 модулей (треков), 17 уроков, 20 заданий
- Покрытие: ~10 из 16 номеров КИМ
- Seed: `packages/db/seed/oge-course.ts`

### 3. Курс ОГЭ 2027 (`oge-informatika-2027`)
- 4 модуля (по разделам кодификатора), 16 уроков, ~100 заданий
- Покрытие: все 16 номеров КИМ (8–10 заданий на каждый)
- Интерактивный тренажёр «Робот» (браузерный)
- Seed: `packages/db/seed/oge-course-2027.ts`
- Данные: `packages/db/seed/data/oge-informatika-2027.ts`

### 4. Страницы (Next.js App Router)

| URL | Назначение |
|-----|------------|
| `/courses/oge-informatika-2026` | Лендинг ОГЭ 2026 |
| `/courses/oge-informatika-2027` | Лендинг ОГЭ 2027 |
| `/oge/modules/[slug]` | Страница модуля: уроки + задания |
| `/oge/lessons/[slug]` | Просмотр урока с Markdown |
| `/oge/tasks/[id]` | Задание с вводом ответа и проверкой |
| `/oge/progress` | Дашборд прогресса по модулям |
| `/oge/exam` | Список пробных вариантов |
| `/oge/robot-simulator` | Интерактивный тренажёр Робота (задание 15) |

### 5. API
- `POST /api/oge/submit-task` — сохранение ответа, обновление прогресса
- `POST /api/execute` — существующий code-runner (Docker-песочница)

### 6. Seed-скрипты

```bash
pnpm db:seed              # основной сид (контент + курсы + треки + OGE 2026)
pnpm db:seed:oge          # только OGE 2026
pnpm db:seed:oge2027      # только OGE 2027
pnpm db:seed:oge-exams    # пробные варианты (5 штук)
pnpm db:seed:all          # всё вместе (2026 + 2027)
```

### 7. Интеграция
- Навигация: ссылки «ОГЭ 2026» и «ОГЭ 2027» в топ-меню
- Track redirect: OGE-треки перенаправляются на `/oge/modules/[slug]`
- Code runner: готов для Python (задание 16) — существующий Docker-песочница
- Exam system: реиспользуется для пробных вариантов
- Тренажёр Робота: встроенный в браузер, не требует внешней среды

## Требования для запуска

1. Node.js 20+, pnpm
2. PostgreSQL (или через Docker Compose)
3. Docker (для code-runner с Python/Go/SQL)

```bash
pnpm install
pnpm db:seed:all
pnpm dev
```
