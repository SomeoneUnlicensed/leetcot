## Полные миски

В приюте записали, сколько граммов корма лежит в каждой миске. Миска считается полной, если в ней не меньше `limit` граммов.

### Задание

Реализуйте функцию `CountFullBowls(fish []int, limit int) int`, которая возвращает количество полных мисок.

```go
CountFullBowls([]int{3, 8, 10, 2}, 8) // 2
```
