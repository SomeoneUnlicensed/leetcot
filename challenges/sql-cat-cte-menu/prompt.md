## Меню больших охотников (CTE)

В таблице `orders` записаны заказы котов на рыбном рынке.

С помощью CTE посчитайте суммарный вес рыбы для каждого кота и верните только тех, у кого `total_grams` не меньше `300`.

Верните `cat` и `total_grams`, отсортируйте результат по имени кота.

### Таблица

- `orders` (cat, fish, grams)
