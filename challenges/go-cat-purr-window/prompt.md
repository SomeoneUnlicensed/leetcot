## Окно мурчания

Кот идет по клавиатуре и оставляет строку символов. Нужно найти самый длинный непрерывный фрагмент, где ни один символ не повторяется.

### Задание

Реализуйте `LongestPurrWindow(s string) int`.

```go
LongestPurrWindow("abca") // 3, фрагмент "abc"
LongestPurrWindow("bbbbb") // 1
```
