## Портальный маршрут

Кот перемещается между комнатами по коридорам. После каждого перехода он должен сделать `cooldown` пауз, прежде чем снова использовать дорогой портал.

### Задание

Реализуйте `MinPortalCost(n int, edges []Edge, start, finish int, cooldown int) int`.

`Edge{From, To, Cost, Portal}` задаёт направленное ребро. Обычные ребра можно использовать всегда. Если `Portal == true`, после такого ребра следующие `cooldown` шагов нельзя использовать портальные ребра. Если пути нет, верните `-1`.

```go
MinPortalCost(3, []Edge{{0, 1, 5, true}, {1, 2, 1, true}, {0, 2, 20, false}}, 0, 2, 1) // 20
```
