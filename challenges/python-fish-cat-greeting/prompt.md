## Приветствие кота

Кот представляется по имени! Верни строку `"Привет, меня зовут {name}!"`.

Реализуй функцию `cat_greet(name)`, которая принимает имя кота и возвращает приветствие.

```python
cat_greet("Барсик")  # "Привет, меня зовут Барсик!"
cat_greet("Кот")     # "Привет, меня зовут Кот!"
```
