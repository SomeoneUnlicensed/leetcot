## Самое длинное мурчание

Кот печатает строку. Нужно найти самый длинный фрагмент, где символы не повторяются.

Реализуйте функцию `longest_purr(s)`, которая возвращает длину самой длинной подстроки без повторяющихся символов.

```python
longest_purr("abcabcbb") # 3
longest_purr("bbbbb")    # 1
```
