## Пьедестал без дырок (DENSE_RANK)

В таблице `catches` записан итоговый улов участников.

Верните `cat`, `fish_count` и `place`, где `place` — место по убыванию `fish_count` без пропусков при равных значениях.

Отсортируйте результат по `place`, затем по имени кота.

### Таблица

- `catches` (cat, fish_count)
