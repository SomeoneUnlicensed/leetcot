## Патруль префиксов

Кот ходит по прямой: `1` — шаг вправо, `-1` — шаг влево. Нужно посчитать, сколько непустых подряд идущих отрезков пути возвращают кота в ту же точку.

Реализуйте функцию `count_balanced_walks(steps)`, которая возвращает количество отрезков с суммой `0`.

```python
count_balanced_walks([1, -1, 1, -1]) # 4
```
