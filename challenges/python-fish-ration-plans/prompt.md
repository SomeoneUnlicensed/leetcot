## Планы ночного пайка (Subset Sum)

У кота есть несколько мисок с разным количеством корма. Нужно понять, сколькими способами можно выбрать часть мисок так, чтобы суммарно получилось ровно `target`.

Каждая миска считается отдельной, даже если в двух мисках одинаковое количество корма.

### Задание

Реализуйте функцию `count_ration_plans(bowls, target)`, которая возвращает число подходящих наборов мисок.

```python
count_ration_plans([2, 3, 5, 5], 10)
# 3
```
