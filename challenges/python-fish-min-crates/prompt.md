## Ящики для тунца (Bitmask DP)

После большого улова коту нужно разложить рыбу по ящикам. В один ящик можно положить несколько рыб, если их суммарный вес не превышает `limit`.

### Задание

Реализуйте функцию `min_tuna_crates(weights, limit)`, которая возвращает минимальное число ящиков, нужных для всех рыб.

Все веса положительные, каждый вес не больше `limit`, количество рыб в закрытых тестах небольшое, но перебор всех разбиений все равно быстро взрывается.

```python
min_tuna_crates([4, 8, 1, 4, 2, 1], 10)
# 2
```
