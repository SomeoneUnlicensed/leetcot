## Индекс лакомств

Коты оставили список заказов. Одно и то же лакомство может быть написано в разном регистре.

### Задание

Реализуйте `BuildSnackIndex(names []string) map[string]int`.

Функция должна привести названия к нижнему регистру и вернуть, сколько раз встретилось каждое лакомство. Пустые строки не учитывайте.

```go
BuildSnackIndex([]string{"Tuna", "tuna", "", "Milk"}) // map[string]int{"tuna": 2, "milk": 1}
```
