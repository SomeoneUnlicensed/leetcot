## Лучшие оценки котят

Дан список попыток котят в формате `(имя, балл)`. У одного котенка может быть несколько попыток.

Реализуйте функцию `best_scores(attempts)`, которая возвращает словарь `{имя: лучший_балл}`.

```python
best_scores([("Mira", 7), ("Mira", 9), ("Bars", 5)]) # {"Mira": 9, "Bars": 5}
```
