## Рыбка-делимость

Кот делит рыбок поровну между котятами! Проверь, делится ли число `a` на `b` без остатка.

Реализуй функцию `is_divisible(a, b)`, которая возвращает `True`, если `a` делится на `b` нацело.

```python
is_divisible(10, 2)  # True
is_divisible(10, 3)  # False
is_divisible(7, 1)   # True
```
