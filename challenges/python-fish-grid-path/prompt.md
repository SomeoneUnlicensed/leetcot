## Короткий путь

Дана сетка из `0` и `1`: `0` — свободная клетка, `1` — стена. Нужно найти длину кратчайшего пути от левого верхнего угла до правого нижнего. Ходить можно по вертикали и горизонтали.

Реализуйте функцию `shortest_grid_path(grid)`. Если пути нет, верните `-1`. Длина пути считается в количестве посещенных клеток.

```python
shortest_grid_path([[0, 0], [1, 0]]) # 3
```
