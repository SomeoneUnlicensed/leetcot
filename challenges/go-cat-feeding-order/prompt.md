## Очередь кормления

Некоторые действия в приюте можно делать только после других: сначала вымыть миски, потом насыпать корм.

### Задание

Дан список зависимостей `Task{Before, After}`: задачу `Before` нужно выполнить до `After`.

Реализуйте `PlanFeedingOrder(tasks []Task) []string`.

Если корректных порядков несколько, на каждом шаге выбирайте лексикографически минимальную доступную задачу. Если есть цикл, верните пустой слайс.

```go
PlanFeedingOrder([]Task{{"wash", "feed"}, {"buy", "feed"}}) // []string{"buy", "wash", "feed"}
```
