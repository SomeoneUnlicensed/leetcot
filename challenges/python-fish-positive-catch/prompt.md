## Положительный улов

Кот хочет знать, положительная ли рыбка попалась! Ноль — не положительный.

Реализуй функцию `is_positive(n)`, которая возвращает `True`, если число больше нуля, и `False` в остальных случаях.

```python
is_positive(5)   # True
is_positive(-3)  # False
is_positive(0)   # False
```
