## Журнал пайков

В журнале каждая строка имеет формат `name:+N` или `name:-N`. Нужно посчитать итоговое изменение запасов.

### Задание

Реализуйте `ParseRationLog(lines []string) (int, error)`.

Правила:

- имя не может быть пустым;
- знак должен быть `+` или `-`;
- число должно быть целым неотрицательным;
- если строка испорчена, верните ненулевую ошибку.

```go
ParseRationLog([]string{"barsik:+10", "mira:-3"}) // 7, nil
```
