## Поворот мисок

Коты разложили миски в ряд, но дежурный кот решил сдвинуть порядок вправо.

Реализуйте функцию `rotate_bowls(bowls, k)`, которая возвращает новый список: элементы списка `bowls` сдвинуты вправо на `k` позиций.

Если список пустой, верните пустой список.

```python
rotate_bowls([1, 2, 3, 4, 5], 2) # [4, 5, 1, 2, 3]
```
