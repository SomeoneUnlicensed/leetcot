## Счетчик лакомств

Коты принесли список лакомств. Нужно понять, сколько раз встречается каждое название.

Реализуйте функцию `count_snacks(snacks)`, которая принимает список строк и возвращает словарь `{название: количество}`.

```python
count_snacks(["fish", "milk", "fish"]) # {"fish": 2, "milk": 1}
```
